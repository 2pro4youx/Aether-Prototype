## 📖 Overview

**AetherApp** is a modern, AI-driven academic workspace engineered to streamline learning, research, and project management for university and high school students. Built on advanced generative AI tooling, AetherApp bridges the gap between complex coursework and efficient comprehension. 

Whether you are synthesizing dense research papers, organizing study schedules, generating flashcards, or debugging code for a computer science lab, AetherApp acts as an intelligent, ethical academic copilot designed to elevate student productivity and foster deeper understanding.

## ✨ Core Academic Features

* **📚 Smart Literature & Note Synthesis:** Transform lengthy lectures, textbooks, and academic PDFs into structured summaries, key takeaways, and actionable study guides in seconds.
* **🧠 Interactive Socratic Tutor:** Go beyond simple answers—engage with an AI assistant trained to guide you through complex STEM problems, humanities essays, and coding challenges step-by-step.
* **🗂️ Automated Study Workflows:** Generate custom flashcards, practice quizzes, and conceptual mind maps tailored directly to your syllabus and learning pace.
* **💻 Distraction-Free Study Environment:** A clean, accessible user interface featuring customizable dark/light modes and responsive layouts for seamless studying across laptops, tablets, and mobile devices.
* **🔒 Privacy-First & Academic Integrity:** Engineered to empower student learning through guided assistance and citation-ready insights while ensuring user data and API credentials remain strictly secure.

## 🛠️ System Architecture & Tech Stack

AetherApp is built using a modern, scalable web stack designed for low-latency AI inference and responsive client-side performance:

* **Frontend Framework:** React, TypeScript, Tailwind CSS
* **AI & LLM Integration:** Google AI Studio / Gemini API (`@google/genai` SDK)
* **State & Build Tooling:** Vite, ESBuild
* **Deployment & Edge Hosting:** AI Studio Cloud Infrastructure

## 🚀 Getting Started (Local Development)

Students and student-developers are encouraged to clone, customize, and build upon AetherApp for hackathons, capstone projects, or personal study setups.

### Prerequisites

Ensure you have the following installed on your local machine:
* [Node.js](https://nodejs.org/) (v18.0.0 or higher)
* `npm` or `yarn` package manager
* A valid API key from [Google AI Studio](https://aistudio.google.com/)

## 💡 Student Use Cases

* **Exam Preparation:** Upload raw lecture notes to automatically generate multi-choice practice exams and active-recall prompts.
* **Research & Writing:** Brainstorm thesis statements, outline academic papers, and check drafts for structural clarity and tone.
* **STEM & Coding Labs:** Analyze time complexity, debug syntax errors, and visualize mathematical concepts interactively.

To experience the live hosted application without local setup, visit **[aetherapp.ai.studio](https://aetherapp.ai.studio/)**.
